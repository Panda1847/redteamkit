# Security policy

RedTeamKit is designed for authorized security testing and defensive validation only. Do not use it against systems, identities, or data without written permission and a defined scope.

## Reporting a vulnerability

Please use a private GitHub security advisory rather than a public issue. Include the affected version, a minimal reproduction, impact, and any safe mitigation. Do not include secrets, customer data, or operational infrastructure details.

## Scope and safety

The project deliberately avoids network calls and requires real result data for reporting. Destructive techniques are excluded by default. Treat every campaign plan as a controlled lab or explicitly authorized engagement artifact.
