# RedTeamKit v3.2 presentation

This folder contains the release briefing for RedTeamKit v3.2 and its MITRE ATT&CK synchronization features.

- [PDF release briefing](./RedTeamKit-v3.2-ATTACK-Sync-Safety.pdf)
- [Editable HTML slide deck](./v3.2/)

The HTML deck is composed of eight self-contained slides and can be opened directly from a local checkout or served through GitHub Pages. It covers:

- v3.2 release evolution
- ATT&CK v20.0 STIX synchronization
- offline seed versus full refresh
- curated and generated profile precedence
- executable safety controls
- verification metrics and CLI commands

The content is for authorized defensive security work only.
